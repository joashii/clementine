# CMSC 141 Exam 12: Limits of Computation, Undecidability, and Complexity (Lecture 18)

**Items:** 20 | **Difficulty:** Average | **Type:** Application, multiple choice

**Directions:** Choose the best answer: **a, b, c, d**, or **e** (none of the above).

---

**1.** Which statement is the Church–Turing thesis?
- a. Every TM can be simulated by a finite automaton
- b. Every effectively calculable function is computable by a Turing machine
- c. Every function is computable
- d. Every language is context-free
- e. None of the above

**2.** Let G be the sentence "This statement is not provable in F", for a sound, consistent formal system F capable of expressing arithmetic. What is G?
- a. False and provable
- b. False and unprovable
- c. True and provable
- d. True but not provable in F
- e. None of the above

**3.** In a diagonal argument on reals in (0,1), the diagonal digits are 3, 0, 9, 4. Adding 1 to each digit (9 becomes 0) gives the first digits of the new number x. Which is x?
- a. 0.4105
- b. 0.3094
- c. 0.4015
- d. 0.4106
- e. None of the above

**4.** In the diagonal argument for languages, the membership bits on the diagonal (L₁ on w₁, ..., L₄ on w₄) are 1 1 0 1. What are the first four bits of the new language L_D?
- a. 1101
- b. 0010
- c. 0101
- d. 1010
- e. None of the above

**5.** Turing machines can be listed one by one, but the set of all languages cannot. Therefore:
- a. Every language is decidable
- b. Every language is acceptable
- c. Some language has no Turing machine
- d. All languages are regular
- e. None of the above

**6.** How is { aⁿbⁿcⁿ | n ≥ 0 } classified?
- a. Decidable
- b. Acceptable but not decidable
- c. Not Turing-acceptable
- d. Regular
- e. None of the above

**7.** A language L is Turing-acceptable, and its complement is also Turing-acceptable. What follows?
- a. L is undecidable
- b. L is finite
- c. L is regular
- d. L is decidable
- e. None of the above

**8.** How is HALT = { ⟨M, w⟩ | M halts on w } classified?
- a. Decidable
- b. Not acceptable
- c. Acceptable but not decidable
- d. Regular
- e. None of the above

**9.** In the proof that HALT is undecidable, D reads an encoded TM and does the opposite of what H predicts. H is run on ⟨D, ⟨D⟩⟩ and predicts that D halts on its own code. What does D actually do?
- a. Halts
- b. Accepts
- c. Rejects
- d. Loops forever
- e. None of the above

**10.** How is co-HALT classified?
- a. Decidable
- b. Not Turing-acceptable
- c. Acceptable but not decidable
- d. Regular
- e. None of the above

**11.** Which of these problems is undecidable?
- a. Does the Turing machine M halt on input w?
- b. Is a given number prime?
- c. Does a DFA accept ε?
- d. Is a string w in a given CFL?
- e. None of the above

**12.** Which question about a context-free grammar G is undecidable?
- a. Is a given string w generated by G?
- b. Is L(G) empty?
- c. Is L(G) regular?
- d. Is G in Chomsky Normal Form?
- e. None of the above

**13.** To verify that {B, C, D, E} is a clique in a graph, how many pairs of vertices must be checked?
- a. 4
- b. 8
- c. 12
- d. 6
- e. None of the above

**14.** Verifying that a proposed vertex sequence is a Hamiltonian cycle in an n-vertex graph takes:
- a. O(n)
- b. O(n!)
- c. O(2ⁿ)
- d. O(nⁿ)
- e. None of the above

**15.** Which problem is solvable in polynomial time?
- a. Clique
- b. Shortest path with nonnegative weights (Dijkstra)
- c. Hamiltonian cycle
- d. SAT
- e. None of the above

**16.** Which problem was the first proven NP-complete (Cook–Levin Theorem)?
- a. SAT
- b. Dijkstra's shortest path
- c. HALT
- d. Clique
- e. None of the above

**17.** Which relationship is known to hold?
- a. P = NP-hard
- b. NP ⊂ P
- c. P ⊆ NP
- d. NP-complete ⊆ P
- e. None of the above

**18.** A brute-force Hamiltonian cycle search on a 5-vertex graph tries all permutations of the vertices. How many permutations is that?
- a. 25
- b. 120
- c. 32
- d. 10
- e. None of the above

**19.** Problem A reduces to problem B in polynomial time. What does this give you?
- a. A is harder than B
- b. B cannot be solved
- c. A and B are the same problem
- d. An algorithm for B plus the transformation solves A
- e. None of the above

**20.** Which of these is currently known to be true?
- a. P = NP
- b. P ≠ NP
- c. Every NP-complete problem is in P
- d. The halting problem is decidable
- e. None of the above (whether P = NP is still open)
