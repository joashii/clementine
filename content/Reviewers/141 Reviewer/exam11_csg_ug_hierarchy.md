# CMSC 141 Exam 11: Context-Sensitive and Unrestricted Grammars, LBAs, and the Chomsky Hierarchy (Lecture 17)

**Items:** 20 | **Difficulty:** Average | **Type:** Application, multiple choice

**Directions:** Choose the best answer: **a, b, c, d**, or **e** (none of the above). A CSG has productions α → β with |α| ≤ |β| and at least one variable in α; an unrestricted grammar (UG) drops the length restriction.

## Reference Grammars

- **CSG1 (aⁿbⁿcⁿ, n > 0):** S → aBC | aSBC; CB → BC; aB → ab; bB → bb; bC → bc; cC → cc.
- **CSG2 (equal numbers of a's, b's, c's, nonempty):** S → ABC | ABCS; AB → BA; BC → CB; AC → CA; A → a; B → b; C → c.
- **UG1 (a^(2ᵏ), k > 0):** S → <Ca>; Ca → aaC; C> → D>; C> → E; aD → Da; <D → <C; aE → Ea; <E → ε.

## Answer Key

| # | Ans | Why |
|---|-----|-----|
| 1 | d | \|aB\| = \|ab\| and the left side has a variable |
| 2 | c | Regular ⊂ CFG ⊂ CSG ⊂ Unrestricted |
| 3 | b | S → aBC alone only gives abc; n = 2 needs S → aSBC |
| 4 | a | CB → BC swaps C and B |
| 5 | e | 7 applications (2 S-rules, 1 swap, 4 conversions) |
| 6 | c | 3 S-rules + 3 swaps + 6 conversions = 12 |
| 7 | a | aabbcc = a²b²c² |
| 8 | b | context c on the left, A = C, β = c |
| 9 | c | 4 symbols + 2 endmarkers |
| 10 | a | LBA restrictions |
| 11 | c | aaaa = a⁴ = a^(2²) |
| 12 | a | S → <Ca>, Ca → aaC, C> → E, aE → Ea twice, <E → ε |
| 13 | b | C doubles each a |
| 14 | c | lengths are 2ᵏ with k ≥ 1 |
| 15 | a | context-sensitive, not context-free |
| 16 | b | S → aSa \| bSb \| c |
| 17 | d | UG ↔ TM |
| 18 | c | encoded M and input w |
| 19 | b | cab has one of each |
| 20 | e | all four have \|α\| ≤ \|β\| with a variable on the left |
