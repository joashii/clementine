# CMSC 141 Exam 2: Context-Free Grammars (Lecture 9)

**Items:** 20 | **Difficulty:** Average | **Type:** Application, multiple choice

**Directions:** Choose the best answer: **a, b, c, d**, or **e** (none of the above). In every grammar, S is the start variable. P denotes the palindrome grammar S → ε | a | b | aSa | bSb.

---

**1.** Which grammar generates { aⁿbⁿ⁺¹ | n > 0 }?
- a. S → aSb | b
- b. S → aSb | ab
- c. S → aSb | abb
- d. S → aSbb | abb
- e. None of the above

**2.** Which grammar generates { aⁿb²ⁿ⁺¹ | n > 0 }?
- a. S → aSbb | abb
- b. S → aSb | abbb
- c. S → aSbbb | ab
- d. S → aSbb | abbb
- e. None of the above

**3.** Which string is generated by S → aSb | ab?
- a. `aabb`
- b. `aab`
- c. `abb`
- d. `ba`
- e. None of the above

**4.** For G: S → aSb | abb, how many production applications derive `aabbb`?
- a. 1
- b. 2
- c. 3
- d. 4
- e. None of the above

**5.** Which sequence of productions (applied in order, always to the only variable) derives `babab` in P?
- a. S → aSa, S → bSb, S → b
- b. S → bSb, S → bSb, S → a
- c. S → bSb, S → aSa, S → b
- d. S → bSb, S → aSa, S → a
- e. None of the above

**6.** Which of these strings is **not** generated by P?
- a. `abba`
- b. `aba`
- c. `bbbb`
- d. `a`
- e. None of the above (all are generated)

**7.** Which grammar generates exactly the palindromes over {a,b} that begin and end with `a`?
- a. S → aPa | a; P → ε | a | b | aPa | bPb
- b. S → aSa | bSb | a
- c. S → aSa | a | aa
- d. S → aPa; P → ε | a | b | aPa | bPb
- e. None of the above

**8.** G: S → aab | aSB, B → b | ε generates { aᵐbⁿ | m > n > 0 }. Which of these strings is **not** generated by G?
- a. `aab`
- b. `aaab`
- c. `aaabb`
- d. `aaaabb`
- e. None of the above (all are generated)

**9.** G: S → aSc | T, T → bTc | ε generates { aᵐbⁿcᵐ⁺ⁿ }. Which string is **not** generated?
- a. `abcc`
- b. `bbcc`
- c. `aacc`
- d. `abbc`
- e. None of the above

**10.** Which grammar generates { aⁿbⁿcᵐ | n, m ≥ 0 }?
- a. S → aSb | cS | ε
- b. S → aSbc | ε
- c. S → XC; X → aXb | ε; C → cC | ε
- d. S → aSb | abc
- e. None of the above

**11.** Which grammar generates { x c xᴿ | x ∈ {a,b}* }?
- a. S → aSa | bSb | c
- b. S → aSb | bSa | c
- c. S → aSa | bSb | ε
- d. S → SS | c
- e. None of the above

**12.** What language does S → AX; A → a | aA; X → ab | aXb generate?
- a. { aⁿbⁿ | n > 0 }
- b. { aᵐbⁿ | m ≥ n > 0 }
- c. { aᵐbⁿ | m > n > 0 }
- d. { aᵐbⁿ | n > m > 0 }
- e. None of the above

**13.** Which sequence of productions derives `(()())` in S → (S) | SS | ()?
- a. S → SS, S → (S), S → (), S → ()
- b. S → SS, S → (), S → (), S → (S)
- c. S → (S), S → (), S → (), S → SS
- d. S → (S), S → SS, S → (), S → ()
- e. None of the above

**14.** G: S → aaSb | a | aab generates { aⁿb^⌊n/2⌋ | n > 0 }. Which string does it generate?
- a. `aabb`
- b. `aaab`
- c. `aaabb`
- d. `aaaab`
- e. None of the above

**15.** In the parse tree of `aaabbb` for G: S → aSb | ab, how many internal nodes are labeled S?
- a. 2
- b. 4
- c. 5
- d. 6
- e. None of the above

**16.** Which grammar is context-free but **not** regular in form?
- a. S → aS | b
- b. S → Sa | a
- c. S → aA; A → bS | ε
- d. S → aSb | ab
- e. None of the above

**17.** The grammar S → SS | (S) | [S] | () | [] generates balanced sequences of parentheses and brackets. Which string does it generate?
- a. `([])`
- b. `([)]`
- c. `(])`
- d. `)(`
- e. None of the above

**18.** G: S → aSb | bSa | SS | ab | ba generates the nonempty strings with equal numbers of a's and b's. Which string is **not** generated?
- a. `abba`
- b. `baab`
- c. `aab`
- d. `aabb`
- e. None of the above

**19.** How many strings of length 4 does S → aSb | ab generate?
- a. 0
- b. 1
- c. 2
- d. 4
- e. None of the above

**20.** You must change P (S → ε | a | b | aSa | bSb) so it generates every nonempty palindrome but not ε. Which change works?
- a. Delete S → ε
- b. S → a | b | aSa | bSb
- c. S → aa | bb | aSa | bSb
- d. Replace S → ε with S → aa | bb
- e. None of the above

## Answer Key

| # | Ans | Why |
|---|-----|-----|
| 1 | c | base abb gives n = 1; each aSb adds one a and one b |
| 2 | d | base abbb (n = 1); each step adds a and bb |
| 3 | a | only aⁿbⁿ is generated |
| 4 | b | S → aSb, then S → abb |
| 5 | c | S ⇒ bSb ⇒ baSab ⇒ babab |
| 6 | e | all four are palindromes generated by P |
| 7 | a | S → a covers `a`; aPa covers every longer one |
| 8 | e | aab, aaab, aaabb, aaaabb are all derivable |
| 9 | d | abbc has m = 1, n = 2, so it needs three c's |
| 10 | c | aⁿbⁿ from X, then c's from C |
| 11 | a | mirror pairs around the center c |
| 12 | c | X gives aᵏbᵏ (k ≥ 1), A adds at least one extra a |
| 13 | d | S ⇒ (S) ⇒ (SS) ⇒ (()S) ⇒ (()()) |
| 14 | b | S → aaSb with S → a gives aaab (n = 3, one b) |
| 15 | e | there are 3 S nodes (not offered) |
| 16 | d | a, b, c are right/left-linear; aSb nests |
| 17 | a | (S) with S → [] |
| 18 | c | aab has unequal counts |
| 19 | b | only aabb |
| 20 | d | S → aa | bb restores even palindromes; a or c alone loses some |
